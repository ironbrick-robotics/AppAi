COMPETITIVE ROBOTICS EXERCISES


==========================================
MINI SUMO
==========================================

MS-01 — Opponent Detection

Goal:
Use the opponent detection sensor(s) to determine whether an opponent is detected.

The student should understand:
- sensor reading
- threshold or detection state
- conditional logic


MS-02 — Basic Attack

Goal:
When the opponent is detected, the robot moves toward it.

The student should understand:
- opponent detection
- conditions
- motor control
- relationship between sensor input and robot action


MS-03 — Ring Edge Detection

Goal:
Detect the boundary of the dohyo using the robot's edge/line sensors.

The student should understand:
- sensor values
- boundary detection
- threshold logic


MS-04 — Edge Avoidance

Goal:
When the robot detects the edge of the dohyo, it must stop the attack and move away from the boundary.

The student should understand:
- priority conditions
- sensor-based reaction
- safe movement


MS-05 — Search Strategy

Goal:
Create a simple strategy that allows the robot to search for the opponent when no opponent is detected.

The student should understand:
- robot states
- searching behavior
- movement strategy


MS-06 — Search, Attack and Escape

Goal:
Combine opponent detection, searching, attacking and edge avoidance into one algorithm.

The student should understand:
- multiple conditions
- priority rules
- state-based behavior
- competition strategy


MS-07 — Debugging a Mini Sumo Strategy

Goal:
Analyze a Mini Sumo program that does not behave as expected and identify the cause.

The student should:
- identify the problem
- explain why it occurs
- propose a correction
- evaluate the resulting robot behavior


==========================================
LINE FOLLOWING
==========================================

LF-01 — Line Detection

Goal:
Read the line sensor(s) and determine the position of the robot relative to the line.


LF-02 — Basic Motor Correction

Goal:
Change the speed or direction of the motors according to the detected position of the line.


LF-03 — Two-Sensor Line Following

Goal:
Combine left and right sensor readings to keep the robot following the line.


LF-04 — Speed and Stability

Goal:
Investigate how motor speed affects the stability of line following.


LF-05 — Proportional Control

Goal:
Use the line position error to calculate an appropriate steering correction.


LF-06 — PD/PID Line Following

Goal:
Use proportional and derivative, or PID, control to improve line-following performance.


LF-07 — Debugging a Line-Following Algorithm

Goal:
Analyze incorrect or unstable line-following behavior and identify possible problems in the algorithm or its parameters.
